# Exclusion query, pass 1 (2026-08-06)

CONTRADICTED BY PASS 2. See 20260806-exclusions-CONFLICT.md before using anything here.

1. 「不得」条款
   "已享受公共租赁住房实物配租、公租房货币化补贴、廉租住房实物配租和租赁补贴、
    经济适用住房等保障性住房政策的家庭，不得申请市场租房补贴。"
2. 「除外」/「不适用」— 未检索到
3. 「已享受」— same clause as (1); confirmed 不得同时享受
4. 「停止发放」
   "家庭人均月收入超过规定标准的，自次月起停止发放补贴。"
   "家庭在本市承租公共租赁住房或购买其他住房的，自次月起停止发放补贴。"
5. 骗取/隐瞒/虚报
   "通过虚报、隐瞒等手段骗取补贴的，由区住房保障管理部门取消其市场租房补贴资格，
    已发放的补贴予以追回。"
   "对出具虚假证明材料的单位，由相关部门依法依规追究责任。"
6. 申报期限
   "家庭收入、住房等情况发生变化的，应当在30日内向街道办事处（乡镇人民政府）申报。"
   "未按期申报的，区住房保障管理部门可暂停发放补贴。"
